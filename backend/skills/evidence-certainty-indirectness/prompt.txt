# Evidence Certainty Indirectness V1

Version: `CORE_GRADE_2025_V1`. Currently handles only direct two-arm comparisons, not network indirect comparisons.

1. Compare the target and evidence for population, intervention, comparator, outcome, time horizon, setting, and estimand.
2. Differences do not automatically warrant downgrading. Use `SERIOUS` only when there is a credible reason that a difference importantly changes the magnitude of the intervention effect or the applicable inference.
3. Consider `VERY_SERIOUS` only for very indirect evidence or an unreliable surrogate replacing a patient-important outcome.
4. Differences in outcome definitions or scales belong to inconsistency if they affect only agreement among Study effects, and to indirectness if they make the evidence address a different target question. Do not downgrade twice for the same issue.
5. Judge differences in region, dose, care pathway, or follow-up against the predefined target and plausible effect modifiers; do not downgrade merely because heterogeneity exists.
6. Return `NOT_ASSESSABLE` when target or evidence PICO lacks source-bound facts and cannot be compared.
7. Treat an unrestricted target field as a broad target; do not claim comparison is impossible because the target omits a setting, region, or narrower time horizon. Narrower evidence is a concern only when the difference is a credible effect modifier that may limit target inference.
8. When core evidence and target PICO match directly, but source-bound regimen, outcome definition, severity/core definition, regional care pathways, or similar plausible effect modifiers have uncertain importance, use `BORDERLINE_NOT_SERIOUS_SERIOUS`. If differences exist without a credible pathway to an effect difference, use `NOT_SERIOUS`. Use `NOT_ASSESSABLE` only when the entire target/evidence PICO is missing or too conflicting to compare.
9. Distinguish implementation variation intentionally covered by a broad target from plausible effect modifiers that limit target inference. Without a source-bound reason for an effect difference, the former must be `NOT_SERIOUS`; differing doses, devices, or implementation alone do not justify borderline. For the latter, if sources provide a credible biological/clinical effect-modification pathway but its importance is uncertain, use borderline. Do not require proof of an important effect difference first, as that approaches the standard for definite `SERIOUS`.

The rationale must identify the specific mismatch, explain why it would or would not cause an important effect difference, and cite every input Evidence Fact id.
